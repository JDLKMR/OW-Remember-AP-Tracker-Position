# Remember AP Tracker Position
An Outer Wilds mod that is meant to be installed alongside Ixrec's Outer Wilds Archipelago Randomizer.

It changes one line in the Randomizer mod's code so that the AP Tracker remembers the position you were at in the list and returns you there when backing out of a list entry.

It's also fine to have this installed when the Randomizer mod isn't. It just won't do anything in that case.
